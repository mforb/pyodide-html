: A function with units

Difficulty: ★☆☆


Plan first: write the function contract: input is a Fahrenheit temperature in degrees F, output is a Celsius temperature in degrees C. List the three test values before coding.

Instructions: complete celsius_from_fahrenheit(fahrenheit_f). Return the converted value rather than printing inside the function. Keep the unit-bearing parameter name and use the function for all three supplied values.

Expected output:

98.6 F -> 37.0 C
212.0 F -> 100.0 C
-40.0 F -> -40.0 C

Play around: add 32 F and 0 F to the test values. Check the result against the formula in the Week 1 notes.

Reflection: Why is returning a value more reusable than printing the answer inside the function?

Answer: A returned value can be stored, formatted by the caller, passed to another calculation or tested. Printing only sends text to the console and does not provide a value for later work.


  : A slope-angle function

Difficulty: ★★☆


Plan first: identify the two inputs, the output unit and the formula. The angle is degrees(atan(abs(delta_height_m) / delta_east_m)).

Instructions: complete slope_angle(delta_height_m, delta_east_m). Return the absolute terrain angle in degrees. Use atan() and degrees(); do not use a calculator result as a hard-coded answer.

Expected output:

Angle: 3.43 degrees
Angle: 3.43 degrees

Play around: test a flat route, a negative easting change and a steeper 20 m rise over 100 m. Explain what the absolute value changes.

Reflection: Why should the function return the same angle for a rise of 6 m and a fall of 6 m over the same horizontal distance?

Answer: The steepness magnitude is the size of the angle, not its direction. The sign of the height change tells whether the route rises or falls; abs() removes that direction for a steepness check.

Reflection: Why is > different from >= for an engineering alert threshold?

Answer: > excludes a value exactly at the limit, while >= includes it. The correct operator depends on the stated safety rule and must not be chosen by habit.
